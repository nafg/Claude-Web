# Minimal Bleep Scala Project

A minimal Scala project using Bleep build tool.

## Project Structure

- `bleep.yaml` - Bleep configuration file
- `src/scala/` - Scala source files
- `Hello.scala` - Simple "Hello World" application

## Requirements

- [Bleep](https://github.com/oyvindberg/bleep) build tool
- Java 11 or higher

## Building and Running

```bash
# Compile the project
bleep compile hello

# Run the application
bleep run hello
```

## Project Configuration

- Scala version: 2.13.12
- Platform: JVM
